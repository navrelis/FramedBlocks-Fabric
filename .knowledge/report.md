41 commits on top of the upstream base (3644 files touched incl. the id rename of resources).
- `build.gradle`, `gradle.properties`, `settings.gradle`: Loom 1.15.5 build, compat compile deps, `compat_runtime` dev switch, game test source set (`fabricApi.configureTests`), `runClientDev`.

## 7. Known limitations and recommendations
- Nothing has been play-tested in game; work through §5 before a release.
- Sodium ignores `LevelRenderer.getLightColor` and never calls `Block.shouldRenderFace` (no framed neighbour face hiding, liquid hook inactive under Sodium). ModernFix dynamic resources untested.
- Saw tooltip still shows the unit "FE" (Team Reborn Energy calls it "E").
- JEI pinned to 19.56.0.441 and MezzConfig 0.5.9 because Loom 1.15.5 rejects newer jars; the JEI integration uses 9 API methods marked for removal. Upgrading Loom (needs a newer Gradle) would lift the pins.
- Hopper insert cooldown is a flat 8 ticks (vanilla 7-tick adjustment missing, pre-existing). `FreshBlockEntityQueue` keeps strong references until drained.
- Datagen not ported; generated resources are hand-maintained. New config lang key only in `en_us`.
- Creative tab position relative to spawn eggs dropped.
- `testSignDying` documents an upstream bug (waxed sign wax removal unreachable); 2 duplicate recipe patterns are upstream.
- LGPL: the repository is private. Anyone who distributes the jar must make the corresponding source available (e.g. make the repository public or ship the `-sources` jar).
