Setup

Install in three steps

  1. 1

    Fabric

    Install Fabric Loader 0.19 or newer for Minecraft 1.21.1, and Fabric API.

  2. 2

    Mods folder

    Put the mod into the mods folder of the game, and of the server for multiplayer.

  3. 3

    Play

    Start the game.

Requirements

Java 21. Needed on both the client and the server. Forge Config API Port is bundled.

Not compatible with NeoForge worlds

The mod id is framedblocks_fabric, so worlds and items from the NeoForge version do not carry over.
