Tools

Tools and upgrades

  • Framed Hammer

    Removes the camo and toggles options such as waterlogging.

  • Framed Wrench

    Rotates blocks and switches some shape variants.

  • Framed Screwdriver

    Rotates the camo texture.

  • Framed Key

    Locks the state of a block.

  • Framed Blueprint

    Copies a framed block with its camo. The materials must be in your inventory.

Upgrades

  • Glowstone dust

    The block gives off light.

  • Reinforcement

    A pickaxe that can mine obsidian takes it off.

  • Phantom Paste

    The block becomes intangible (server option).
