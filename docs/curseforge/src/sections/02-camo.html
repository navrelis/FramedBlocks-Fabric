Camouflage

Any block, any shape

A new framed block is an empty wooden frame. Give it the look of almost any block.

  • Right-click with a block

    The framed block takes the look of the block in your hand. Fluids work too.

  • Take it off

    The Framed Hammer removes the camo again.

Not accepted: blocks with block entities and untagged non-solid blocks.
